# F1 - Staging discipline and .gitignore  (Easy)

Run `bash .task/f1-setup.sh` first. It leaves your working tree dirty on purpose.

Your job, in a single commit on `answer/f1`:

1. Add a `.gitignore` at the repo root that keeps `node_modules/`, `.env`
   and every `*.log` file out of version control.
2. Commit `.gitignore`, the new `api/routes/users.js`, and the change to
   `api/server.js` - and nothing else.
3. The commit message must be exactly: `Add users route and ignore build artifacts`

Nothing under `node_modules/`, `api/cache/` or `.env` may be tracked.
