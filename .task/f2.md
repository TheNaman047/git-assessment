# F2 - Split one dirty file into two commits  (Medium)

`shared/validate.js` on this branch already contains three validators, but
they were never split into reviewable commits. On `answer/f2`, rewrite the
history of that single file into TWO commits, in this order:

1. `Add priority validator`  - the file contains `isValidTitle` and
   `isValidPriority` only, and exports exactly those two.
2. `Add due date validator`  - the file additionally contains
   `isValidDueDate` and exports all three.

Start from `seed/f2` and produce the two commits on top of `main`, so that
`git log main..answer/f2 --oneline` shows exactly those two commits.
Hint: `git reset`, `git add -p`, or `git commit --patch` are all fair game.
