# F3 - Detached HEAD rescue  (Hard)

Reproduce and then recover from a detached HEAD.

1. Check out the commit `Accept POST /tasks` **by its SHA** (not by branch
   name). Confirm with `git status` that HEAD is detached.
2. While detached, add a file `api/routes/health.js` with exactly this body:

       function routeHealth(req, res) {
         res.writeHead(200, { 'content-type': 'application/json' });
         res.end(JSON.stringify({ ok: true }));
       }

       module.exports = { routeHealth };

   Commit it with the message `Add health route`.
3. You are now sitting on a commit that no branch points at. Rescue it:
   create branch `answer/f3` pointing at that commit, and push it.

`answer/f3` must have exactly ONE commit on top of `Accept POST /tasks`, and
must NOT contain the `Parse the POST body` commit.
