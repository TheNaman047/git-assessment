# G1 - Fork, branch, pull request  (Easy)

The whole assessment runs from your own fork, so this task is also your setup
check.

1. Fork this repository and clone your fork - **with every branch**, not just
   `main`. Verify with `git branch -r | grep -c seed/` (you should see at
   least 20).
2. Add a `CONTRIBUTORS.md` at the repo root containing exactly one line:
   your GitHub login, nothing else.
3. Commit it on a branch called `answer/g1` with the message
   `Add <your-github-login> to contributors`.
4. Push it to your fork and open a pull request **against this upstream
   repository's `main`**, titled exactly
   `Add <your-github-login> to contributors`.

In SOLUTIONS.md: name the remote that points at your fork and the one that
points at this repository, and give the command that adds the second one.
