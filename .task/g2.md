# G2 - Review someone else's pull request  (Medium)

There is an open pull request on **this upstream repository** from the branch
`review-me/task-filters`, titled "Add filtering and pagination to GET /tasks".

Review it properly. Leave **inline review comments on the specific lines**
(not one lump comment on the conversation tab), and finish the review with an
explicit verdict of "Request changes".

The diff contains several real defects. Finding four of them is a pass;
finding all of them is a distinction. For each one, your comment must say
what is wrong and what it should be instead - "this is wrong" scores nothing.

Do not merge or close the pull request.

In SOLUTIONS.md, list the defects you found, one line each, as
`path:line - problem`.
