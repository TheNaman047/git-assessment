# M2 - Merge with a conflict  (Medium)

`seed/m2-feature` also edited `api/config.js`. Merge it into a branch
`answer/m2` taken from `seed/m2-main`.

Resolve the conflict so the merged file is exactly:

    module.exports = {
      port: 8080,
      timeoutMs: 15000,
      retries: 5,
    };

i.e. keep main's port, take the feature's timeout and retries. Leave no
conflict markers. The result must be a real merge commit with two parents
and the message `Merge branch 'config-tuning'`.

In SOLUTIONS.md, paste the command you used to see the three versions
(base / ours / theirs) of the conflicted file.
