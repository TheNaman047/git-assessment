# R2 - Publishing and retiring branches  (Medium)

Two things, both against your own fork:

1. Create `answer/r2` from `seed/r2`, add a file `docs/DEPLOY.md` containing
   the single line `Deploys run from main.`, commit it with the message
   `docs: describe the deploy source`, and push it so that a bare
   `git push` and `git pull` work from that branch afterwards - i.e. it has
   an upstream tracking ref. Paste the exact command you used into
   SOLUTIONS.md.
2. The branch `seed/r2-stale` is dead. Delete it from your fork **from the
   command line** (not the GitHub web UI). Your local copy may stay.

In SOLUTIONS.md, also explain what `git push -u` writes into `.git/config`.
