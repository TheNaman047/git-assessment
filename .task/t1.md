# T1 - Lightweight vs annotated tags  (Easy)

On the tip of `seed/t1` (no new commits needed - do not create `answer/t1`):

1. Create a **lightweight** tag named `build-t1`.
2. Create an **annotated** tag named `v1.0.0-t1` whose message is exactly
   `TaskFlow 1.0.0`.
3. Push both tags to your fork.

In SOLUTIONS.md: name one thing an annotated tag stores that a lightweight
tag cannot, and give the command that tells the two apart in a fresh clone.
