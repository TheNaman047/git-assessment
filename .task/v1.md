# V1 - Undo a published mistake  (Easy)

`Lower the rate limit for testing` set `MAX` to 0 and was already pushed, so
it must be undone by adding history, not by removing it.

On `answer/v1` (from `seed/v1`), undo exactly that commit. Afterwards:

- `api/rate-limit.js` must have `MAX = 100` again;
- `web/index.html` must keep its `<h1>` heading;
- `answer/v1` must have exactly FOUR commits more than `main`, the newest
  being the undo;
- the commit `Lower the rate limit for testing` must still be in the log.

In SOLUTIONS.md, explain in two sentences why `git reset --hard` was the
wrong tool for a branch other people have already pulled.
