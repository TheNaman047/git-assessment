# TaskFlow - Git Assessment Sandbox

This repository is the practical half of a Git skills assessment. Do not
commit anything to `main`.

Every task lives on its own `seed/*` branch and has its brief in `.task/`. Start each task by branching from its seed:

    git switch -c answer/f1 origin/seed/f1

Read `HOW-TO.md` for the full rules, and the test portal for the theory half.
